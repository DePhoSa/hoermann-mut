# Release 3.4.0

- Spielende: Karte im Spielfeld mit "Nochmal spielen" (Tor-Parcours ohne Countdown), alter Neustart-Link entfernt.
- Rekord mit festem Namen wird automatisch gespeichert, Anzeige auf der Endkarte. Kompaktes Ergebnisblatt.
- Bestenliste: eine Hauptaktion, Online-Abgleich und 0.1-Liste als kleine Links.
- Countdown nach jedem Weiterspielen wieder ab 3.
- Footer schlank, Admin unsichtbar (`#admin` oder Link im Versions-Dialog), Google-Anmeldung (Einrichtung siehe docs/ADMIN.md).
- Handy: Mut-Probe spielbar, Chat-Bedienung, Touch-Texte, größere Ziele.
- Neues Abnahme-System (`tests/abnahme/`), Tests laufen mit Chromium.
Spiele bleiben bei Update 0.2.

## Rückkehr auf 3.3.0
Vorheriges Laufzeitpaket veröffentlichen, keine Datenmigration.
