# 🦁 Hörmann Mut-Portal & Minigame

Ein interaktives, motivierendes Web-Portal im Hörmann-Design mit Mut-Sprüchen, dynamischen visuellen Effekten und einem kurzweiligen Hörmann-Mut-Parcours (Minigame).

## ✨ Features

- **Design exakt nach Vorlage**: Hörmann Corporate Blue (`#002d62`), markante Akzente in Hörmann-Orange (`#f59c00`), klares Typografie-Layout, Datumsanzeige (`WOCHE X - WOCHENTAG`) und dezentes Branding.
- **Button: „Gib mir Mut“**:
  - Über 50 kuratierte, tiefgründige und aktivierende Mut-Sprüche (Philosophen, Lebensweisheiten, Handwerks- & Hörmann-Motive).
  - Dynamischer Muteffekt bei jedem Klick:
    1. 🎉 **Konfetti-Regen**: Bunte und goldene Konfetti-Partikel.
    2. 🙌 **Jubelnde Hände & Kraft**: Aufsteigende Jubel- und Power-Emojis.
    3. 🚪 **Hörmann Sektionaltor-Öffnung**: Animiertes Sektionaltor hebt sich und gibt den Blick frei.
    4. ✨ **Goldener Mut-Schein**: Strahlende Licht-Aura.
    5. 🎆 **Mut-Feuerwerk**: Bunte Funkenexplosionen.
    6. ❤️‍🔥 **Herzklopfen & Puls**: Pulsierende Energiewelle.
    7. 🚀 **Raketen-Durchbruch**: Dynamischer Vorwärtsschub.
  - Sound-Effekte via Web Audio API (ohne externe Sound-Dateien, stummschaltbar über das Lautsprecher-Symbol in der Kopfleiste).
  - Zwischenablage-Funktion („Spruch kopieren“).
- **Notiz-Funktion: „3 Gedanken zu Mut notieren“**:
  - Direkt integriert, basierend auf der Original-Vorlage („Was bedeutet Mut für Sie?“).
  - Speichert Notizen lokal im Browser (LocalStorage).
- **Button: „Das Mut-Spiel“**:
  - Hörmann Tor-Parcours mit Sektionaltoren, Schwingtoren, Brandschutztüren und Stahlzargen.
  - Steuerung via Leertaste oder Touch / Klick.
  - Punkte- und Highscore-Zähler (gespeichert im Browser).
  - Aufmunternde Mut-Sprüche nach jedem Spiel.
